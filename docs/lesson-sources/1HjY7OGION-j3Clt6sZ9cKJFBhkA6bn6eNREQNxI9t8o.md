## **Possessive endings** 

  

1.  SOFT vowels (smiley ones): **ә, ө, ү, і, е / гүл , тіл**
2.  STRONG vowels: **а, о, ұ, у, ы, я, и, ю**

<!-- end list -->

1.  VOICED: **з, ж**

 1a. voiced sonorants: **м, н, ң / л, р, й, у**

1.  VOICELESS:  **п, ф, с, ш, к, қ, т, ч, щ, ц, х, һ, б, в, ғ, г, д**

  
  

**1 person:** -ым, -ім, -м = **my** …. : үйім (my house), жазым (my summer), алмам (my apple), інім (my little brother)

 last letter is a consonant AND it has soft vowels → -ім

 last letter is a consonant AND it has strong vowel → -ым

 last letter is a vowel → -м

  

менің = my

**1 person plural:** -ымыз, -іміз, -мыз, -міз = **our** ….: үйім**і**з (our house), жазымыз (our summer), алмамыз (our apple), іні-міз

last letter is a consonant AND it has soft vowels → -іміз

 last letter is a consonant AND it has strong vowel → -ымыз

 last letter is a vowel AND it has soft vowels → -міз

last letter is a vowel AND it has strong vowel → -мыз 

  

біздің - our

мысық → мысығ**ымыз**

қыз → қыз**ымыз**

үй → үй**іміз** 

жұмыс → жұмыс**ымыз**

  
  

біздің телефонымыз

(in most cases we omit plural endings -лар -лер … for this pronoun)

  
  

**2 person sing/pl informal:** -ың, -ің, -ң = **your** … үйің, жазың, алмаң, інің

last letter is a consonant AND it has soft vowels → -ің

 last letter is a consonant AND it has strong vowel → -ың

 last letter is a vowel → -ң

  

сенің = your (sing inf)

сендердің = your (pl inf)

қызың - your daughter 

  
  
  
  

**2 person sing/pl formal:** -ыңыз, -іңіз, -ңыз, -ңіз = **your formal**…: сіздің үйіңіз, сіздің жазыңыз, сіздің алмаңыз

 last letter is a consonant AND it has soft vowels → -іңіз

 last letter is a consonant AND it has strong vowel → -ыңыз

 last letter is a vowel AND it has soft vowels → -ңіз

 last letter is a vowel AND it has strong vowel → -ңыз

сіздің = your (formal)

  

**3 person:**  -ы, -і, -сы, -сі = **his/her/its** …:. үйлері, жазы, алмас**ы**, інісі

 last letter is a consonant AND it has soft vowels → -і

 last letter is a consonant AND it has strong vowel → -ы

 last letter is a vowel AND it has soft vowels → -сі

 last letter is a vowel AND it has strong vowel → -сы

оның = his/her/its/their
